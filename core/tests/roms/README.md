# External test ROMs

No downloaded ROMs are committed or bundled in the app. Synthetic test cartridges
are generated by tests and contain only small programs written for this project.

## nestest

Put `nestest.nes` and `nestest.log` here, then run:

```sh
cargo test -p nes-core --test nestest
```

The harness compares parsed CPU register/cycle state with the reference trace.
Without both files it prints a skip note. For a visible note, use `-- --nocapture`.

## CPU, APU, PPU and MMC3 suites

Use an external checkout of the [test-ROM collection](https://github.com/christopherpow/nes-test-roms).
The suite authors and their sources/readmes are included there. Keep downloaded
binaries outside the repository or under this ignored directory.

```sh
python3 scripts/check-roms.py /path/to/nes-test-roms --report /tmp/accuracy.json
```

This explicitly runs 39 ROMs: 16 `instr_test-v5`, 8 `apu_test`, 10 `ppu_vbl_nmi`,
and MMC3 tests 1–5. MMC6 is a different board variant and is not included in this
pass claim. Other suites require their own result protocols and are not silently
counted as passing.

A single ROM using blargg's `$6000` status/signature protocol can run with:

```sh
cargo run --release -p nes-runner -- rom-test /path/to/test.nes 1800
```

A failure or timeout produces a nonzero exit code and the ROM's diagnostic text.
