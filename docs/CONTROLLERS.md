# Controllers and two players on Android

Open **Settings → Controllers** from the shelf, or **Controllers** in a paused
game. The list shows the devices controlling Player 1 and Player 2. Connect a
USB or Bluetooth controller or keyboard to make it appear in the list.

1. Select the device by name.
2. Choose **Player 1**, **Player 2**, or **Not assigned**. The choice is saved for
   that device, including across app restarts and reconnects.
3. Choose **Set buttons** and press the physical buttons you want for NES A, B,
   Select and Start. The screen names the selected device and player throughout.
   Only that device can supply a mapping. Different devices retain separate maps.
4. Return to the game and choose its two-player mode, if it supports one.

Directions use the D-pad or stick, or keyboard arrows. Shoulder buttons remain
rewind/fast-forward controls. Press Esc or choose Cancel to leave the wizard
without replacing the previous mapping. Other keyboards/remotes can navigate
to Cancel while the selected controller is being configured.

Without explicit assignments, keyboards and remotes share Player 1 with touch;
the first two gamepads to be assigned use Player 1 and Player 2. Using a keyboard
first does not consume a gamepad's Player 1 port. The controller list resolves
connected devices' defaults so the displayed player matches gameplay.

You can deliberately assign multiple devices to the same player; their buttons
combine. Assign different players for two-player play. Touch always uses Player 1.
**Not assigned** disables a device's game input while allowing menu navigation.
A mapped Start resumes the main pause menu; it cannot resume behind setup screens.

Mappings and explicit player choices use Android's vendor/product/descriptor
identity rather than the temporary device number. Moving a controller to a USB
port that changes its Android descriptor may require setting it up again.
